# Petty cash checklist

A petty cash float only works if every taka/dollar out has a voucher. This is the
minimum system for a small office.

## Set up
- [ ] Fixed float amount, one named custodian, one locked box / wallet
- [ ] A spending cap per voucher (above it, use a bank payment instead)
- [ ] Cost codes agreed in advance (e.g. OFFICE, TRAVEL, SUPPLIES, REPAIRS)

## Every payment out
- [ ] A petty cash voucher: date, amount, purpose, cost code, payee/vendor name
      → https://www.kitovo.app/cash-receipt-template/ (Petty Cash Voucher mode)
- [ ] The vendor's slip/receipt attached or noted on the voucher
- [ ] Three signatures: Issued by, Received by, Approved by — no voucher is valid
      with the same person in all three boxes

## Weekly / monthly
- [ ] Cash in box + total of vouchers = float amount. Investigate any difference
      the same day, while people remember.
- [ ] Reimburse exactly the total of approved vouchers, and file them by month
- [ ] Lost a vendor slip? Note it on the voucher and document the expense honestly:
      https://www.kitovo.app/lost-receipt-replacement/
