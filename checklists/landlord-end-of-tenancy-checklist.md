# Landlord end-of-tenancy checklist

Closing out a tenancy cleanly is mostly a paperwork exercise. Do these in order and
both sides keep a copy of everything.

## Final month
- [ ] Final rent receipt covering the last rent period (start/end dates, amount, method)
      → Bulk-generate the whole tenancy in one PDF if receipts are missing for past
        months that were genuinely paid: https://www.kitovo.app/rent-receipt-template/
- [ ] Meter readings / final utility bills noted with dates and photos

## Security deposit return
- [ ] Original deposit amount and the date it was received
- [ ] Itemised deductions only — each with a reason and, where possible, a bill:
      unpaid rent, cleaning, repairs beyond normal wear, missing items
- [ ] Net refund = deposit − total deductions (if deductions exceed the deposit,
      state the balance owed instead of a negative refund)
- [ ] Issue the statement as a document both sides sign — Kitovo's rent generator has
      a Security Deposit Return mode that produces exactly this breakdown:
      https://www.kitovo.app/rent-receipt-template/
- [ ] Record how and when the refund was paid (bank reference or cash receipt)

## Handover
- [ ] Keys returned and noted, forwarding address for the tenant
- [ ] Copies shared: final receipt + deposit statement to the tenant, originals kept
      by the landlord for the local record-retention period
